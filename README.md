# Financial Performance Analysis using PostgreSQL

## 📌 Project Overview

This project analyzes the financial performance of publicly listed companies using PostgreSQL.

The analysis focuses on revenue, profitability, financial health, growth, benchmarking, and advanced business insights through a series of business-driven SQL queries.

The objective is to demonstrate practical SQL skills commonly used by Data Analysts and Financial Analysts while extracting meaningful insights from financial data.

---

## 📊 Dataset

The dataset contains financial information for publicly listed companies across multiple industries and sectors.

### Key attributes include:

- Company Name
- Ticker
- Exchange
- Sector
- Industry
- Revenue
- Net Income
- Revenue Growth
- Gross Margin
- Operating Margin
- Net Margin
- Return on Assets (ROA)
- Return on Equity (ROE)
- Debt-to-Equity Ratio
- Current Ratio
- Free Cash Flow
- Total Assets

---

## 🎯 Project Objectives

This project aims to answer business questions related to:

- Company & Market Overview
- Revenue Analysis
- Profitability Analysis
- Financial Health Analysis
- Growth Analysis
- Financial Benchmarking
- Advanced Business Insights

---

## 🛠 SQL Concepts Demonstrated

- Filtering (WHERE)
- Aggregate Functions (SUM, AVG, COUNT, STDDEV)
- GROUP BY
- HAVING
- CASE Expressions
- Common Table Expressions (CTEs)
- INNER JOIN
- Scalar Subqueries
- Window Functions (DENSE_RANK)
- Business KPI Analysis
